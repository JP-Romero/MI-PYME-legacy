# MI-PYME

Este es un proyecto de gestión empresarial que incluye funcionalidades como punto de venta, gestión de inventario y reportes. Actualmente, el proyecto está en desarrollo y se están implementando nuevas características.

## Características principales:
- Gestión de productos
- Control de stock
- Procesamiento de ventas
- Generación de reportes

## Instalación
1. Clona el repositorio
2. Instala las dependencias con `npm install`
3. Ejecuta la aplicación con `npm start` (o `npm run dev`)
